# Sprout Work — 사용성 개선 계획서

_작성: 2026-07-30 · 실사용 테스트 기반_

## 목표
많은 사람들이 **불편함 없이 업무를 기록**하는 것. 그 관점에서 핵심 흐름
(작업 기록의 간편함, 시간 기록의 정확성, 시간 초과·부재중 관리, PC 복귀 후 시간 보정)과
모바일/데스크톱 UI를 실제로 사용하며 점검했다.

## 테스트한 흐름
- 신규 작업 시작(입력 → Start), 시간 카운트다운, 일시정지/재개
- 시간 초과(overtime) 알림·탭 제목 깜빡임
- 부재중(idle) 감지 → 자동 일시정지 + 전환 모달
- PC 복귀 후 시간 보정(자리비움 시간 포함/제외)
- 하위작업(트리) 생성(Switch) 및 중첩
- 내일 계획(미완료 가지) + Todo 연동
- 모바일/데스크톱 반응형 레이아웃

## 이번에 수정 완료 (배포됨)

| # | 문제 | 심각도 | 조치 |

| 2 | **모바일에서 타이머가 맨 아래.** GridStack 1열 재배치가 카드를 뒤섞어, 가장 중요한 타이머/시작 카드가 빈 카드 6개(2340px) 아래에 묻힘. | 중대 | 1열일 때 우선순위 정렬(타이머→트리→Todo→계획→오늘→어제→달력). 데스크톱 레이아웃은 캡처·복원. |

| 4 | 영문 부재중 문구 `"1 minutes"` 복수형 오류. | 소 | 숫자 무관한 `"min"` 표기로 변경. |
| 5 | 내일 계획에 **현재 작업 중인 작업/그 부모**가 "미완료"로 표시됨. | 중 | 활성 작업과 그 조상 체인을 플랜에서 제외. |
| 6 | 내일 계획 항목을 처리(오늘 시작/+Todo)해도 목록에 계속 남음. | 중 | 처리 시 플랜에서 자동 제거(`planDismissed`, 클라우드 동기화). +버튼 추가. |

| 8 | **하위작업 추가 발견성 없음(P1).** 계층이 `Switch`+드래그로만 생성돼 처음 쓰는 사람이 알기 어려움. | 높음 | 트리 노드마다 hover `+` 버튼 추가 → 해당 노드의 하위작업으로 모달을 엶. |

## 남은 개선 제안 (미반영 · 우선순위순)

### P2 — 모바일 빈 카드 높이
- **현상**: 모바일에서 각 카드가 내용과 무관하게 ~350px 고정 → 빈 위젯도 화면을 꽉 채워 스크롤 과다.
- **제안**: 모바일에서 카드 높이를 내용에 맞게 축소(min-height 완화), 또는 비어있는 저우선 위젯 접기.

### P2 — "Tomorrow's plan (unfinished)" 위젯명 이중 의미
- **현상**: 이름은 "내일 계획"인데 실제로는 **오늘 멈춘 작업 + 어제 미완료**를 보여줌. 하루 중에는 "지금 멈춰둔 작업 목록"으로 읽혀 혼란.
- **제안**: 명칭을 "이어서 할 작업" 등으로 조정하거나, 상단에 설명 문구 추가.

### P3 — 라이브 리사이즈 전환 매끄러움
- **현상**: 데스크톱↔모바일 폭 경계를 실시간으로 오갈 때 그리드가 잠깐 흐트러질 수 있음(리로드 시 정상). 신규 로드는 양쪽 모두 정상.
- **제안**: GridStack 컬럼 전환 이벤트에 맞춘 레이아웃 복원 정교화(필요 시 전용 모바일 레이아웃 검토).
